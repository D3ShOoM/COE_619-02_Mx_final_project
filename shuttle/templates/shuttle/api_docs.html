Demo API

JSON endpoints for rider app, dashboard, and device ingestion

These endpoints are intentionally simple so they can be shown during the demo and swapped with protobuf GTFS-Realtime later.

Read endpoints

GET /api/stops/
GET /api/vehicles/
GET /api/feed-health/
GET /api/logs/
GET /api/history/BUS-01/
GET /api/gtfs-rt/vehicle-positions/
GET /api/gtfs-rt/trip-updates/

Device ingestion examples

curl -X POST http://127.0.0.1:8000/api/ingest/gps/ \
  -H "Content-Type: application/json" \
  -d '{"bus_id":"BUS-01","lat":26.3074,"lon":50.1492,"speed_mps":5.2,"heading":87,"source":"device-demo"}'
curl -X POST http://127.0.0.1:8000/api/ingest/occupancy/ \
  -H "Content-Type: application/json" \
  -d '{"bus_id":"BUS-01","count":18,"boardings":3,"alightings":1,"source":"dual-ir-demo"}'

Response purpose

VehiclePositions returns latest bus coordinates, bearing, speed, timestamp, and occupancy status. TripUpdates returns per-stop ETA estimates and arrival timestamps for each bus.
